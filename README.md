# Blessed Kyakilika Personal Website

This project is a responsive personal website for Blessed Kyakilika, a Computer Science student learning web technologies. It includes information about the student, project highlights, learning plan, photo gallery, media section, and contact form.

## Included features

- Responsive HTML5 layout with semantic sections
- Professional styling and mobile-friendly design
- Gallery viewer with Previous and Next controls
- Theme switcher for light and dark modes
- Expandable FAQ content
- Contact form validation and local preview summary

## How to test locally

1. Open the project folder in VS Code.
2. Launch Live Server or open `index.html` in a browser.
3. Test the menu, gallery controls, theme toggle, FAQ buttons, and the contact form.
4. Confirm the JavaScript runs without browser errors in the console.

## Files

- `index.html` – main page content
- `css/styles.css` – styling for the full website
- `js/script.js` – JavaScript logic for interactivity
- `images/` – local gallery images
- `videos/` – media files for the site

## Sources

The site uses student-created content and local media assets stored in the project folder.
